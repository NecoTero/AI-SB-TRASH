# Правила рабочей папки SB

## Изоляция локальных проектов

Каждая отдельная папка первого уровня внутри `C:\SB` — самостоятельный **локальный проект**. Граница проекта совпадает с границей его папки.

- После выбора проекта все чтение, поиск, анализ, запуск команд и изменение файлов выполнять только внутри папки этого проекта.
- Не просматривать содержимое соседних проектов, не искать по ним и не использовать их код, данные, документацию, артефакты сборки или настройки как источник для текущего проекта.
- Не копировать, не импортировать, не синхронизировать и не переносить файлы или решения между соседними проектами автоматически.
- Одинаковые имена файлов, сущностей, моделей и функций в разных проектах не означают, что проекты связаны.
- Команды выполнять с рабочей директорией текущего проекта; пути, маски и рекурсивный поиск не должны выходить за его границы.
- На уровне `C:\SB` разрешено только определить нужную папку проекта и прочитать этот общий `AGENTS.md`; рекурсивно исследовать всю рабочую папку нельзя.
- Выход за границы проекта допустим только по отдельному явному запросу пользователя, в котором названы исходный и целевой проекты и требуемое действие.

Локальный `AGENTS.md` внутри проекта может добавлять более строгие правила, но не отменяет эту изоляцию.
