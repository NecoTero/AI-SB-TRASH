Помещайте IFC-модели в эту папку.

Поддерживаемый формат: .ifc
После добавления файлов откройте в прототипе «+ Модель».
Файлы автоматически появятся в окне «Настройка моделей».

Версии задаются именами файлов:
  Model A v1.ifc
  Model A v2.ifc
Файл без суффикса версии считается v1.

При сохранении обрабатываются только новые или изменённые выбранные версии.
Уже прикреплённая неизменённая версия повторно не считывается.

Система реально читает элементы и наборы свойств IFC, затем ищет КФО, корпус и этаж по настроенным признакам.
3D-геометрия пока не отображается.
