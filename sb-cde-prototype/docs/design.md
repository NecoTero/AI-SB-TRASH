# Соответствие экранам дизайна

Источник — документ `Дизайн/Макет.docx`, изображения внутри документа. Интерфейс пересобран по актуальной версии макета. Подписи, относящиеся к бизнес-правилам, сохраняют согласованную логику: архивирование и восстановление графиков, ручной пересчёт IFC, статусы и группа «Без КФО».

| Экран или состояние | Образец в документе | Реализация |
| --- | --- | --- |
| Работы | image20, image30, image34, image35 | Общий верхний блок: навигация проекта, единая панель данных, метаданные, таблица. Переключение источника, версия и дата остаются в одной панели. |
| Версии графика | image22, image29 | Выпадающий список под выбранным графиком, признак актуальной версии, архивирование и восстановление. |
| Отчётная дата | image31 | Календарь под полем даты; недопустимые дни заблокированы. |
| Новый импорт | image17 | Компактное модальное окно, информационная плашка, выбор XLSX, поле даты и действия внизу. |

| Системные настройки | image2, image7 | Отдельная шапка, боковое меню, вкладка мониторинга, поиск и три карточки признаков. |

Названия проекта, организации, модели, авторы и сведения о связанных папках — демонстрационные. Правила обработки источников остаются в core.js. Оформление вынесено в reference.css поверх базовых стилей; шрифты системные, внешних загрузок нет.

Демонстрационная роль выбирается через аватар. Сценарии макета доступны по значку помощи или в меню аватара. Эти элементы позволяют проверять функции при сохранении основной компоновки из документа.
