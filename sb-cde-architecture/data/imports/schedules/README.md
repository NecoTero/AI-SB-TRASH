# Папка импорта графиков проекта

Положите сюда файл `.xml`, затем откройте основной экран приложения `/` — **«Графики проекта»** — и нажмите **«Импортировать из папки»**.

Исходный файл останется в этой папке. Поскольку папка не передаёт бизнес-контекст, приложение создаст отдельный логический график с версией **«Не классифицирован»** и не станет угадывать, является файл базовым или операционным. Для управляемой цепочки `Б1 → О1.1 → О1.2` используйте формы создания графика и добавления версии в интерфейсе.

Управляемая копия сохраняется в `data/schedules/<scheduleId>/versions/<versionId>/source.xml`. Файлы других форматов игнорируются. Уже импортированный файл определяется по SHA-256 и повторно не создаётся. Поддерживаются XML с узлами исходных операций `Task`, `Activity`, `Operation`, `Work` или `Работа`; эти узлы не считаются готовыми работами SB_CDE.
