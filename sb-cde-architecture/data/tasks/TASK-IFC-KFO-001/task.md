# TASK-IFC-KFO-001 — Привязка IFC-элементов к КФО и работам графика

## Цель

Сформировать производное read-only представление:

```text
КФО
  Корпус
    Секция
      Этаж
        Работа со сроками и статусом
          IFC-элементы
```

## Источники

- `public/models/RD_KR_04-08.ifc`;
- базовая версия `Б1` графика `schedule-fe13c646-f17c-480e-ae09-d4bdccd477b9`;
- исходный `source.xml`, сохранённый внутри версии графика.

## Принятые правила

- стабильный ID элемента — IFC `GlobalId`; дополнительно сохраняются `expressId` и Revit `tag`;
- КФО вычисляется по правилам из `reports/IFC_KFO_MAPPING.md`;
- в результат включаются только конструктивные IFC-элементы с геометрическим представлением; все `IFCOPENINGELEMENT` (отверстия, проёмы и термовкладыши) исключаются;
- корпус и этаж берутся из `О_Здание` и `О_Этаж`; отсутствующая секция сохраняется как `unknown`;
- операция XML сначала сопоставляется по `КФО + корпус + этаж`, затем допускается частичное местоположение и только затем КФО без пространства; качество хранится в `scheduleMatchLevel`;
- `SourceStart`/`SourceFinish` остаются исходными сроками XML и не переименовываются в план или прогноз;
- статус вычисляется на дату состояния XML `2026-07-27T08:00:00`, а не на текущую календарную дату.
- цвета и подписи статусов хранятся отдельно в `data/ifc-kfo/statuses.json` и связываются с работой по полю `status`;
- IFC Viewer показывает только привязанные конструктивные элементы и меняет их окраску при перемещении временного ползунка;

## Статусы

- `completed` — заполнен `ActualFinish` или процент выполнения не меньше 100;
- `overdue` — работа не завершена, исходный срок окончания раньше даты состояния XML;
- `in_progress` — заполнен `ActualStart` или процент выполнения между 0 и 100;
- `planned` — исходный старт позже даты состояния XML;
- `not_started` — исходный старт наступил, но факт отсутствует;
- `unknown` — нет подходящих операций или дат.

## Результат

- генератор: `tools/ifc-kfo/build_ifc_kfo_bindings.mjs`;
- данные: `data/ifc-kfo/bindings.json`;
- тесты: `tests/ifc-kfo-bindings.test.ts`.
- справочник статусов: `data/ifc-kfo/statuses.json`;
- read-only API: `/api/ifc-kfo/bindings` и `/api/ifc-kfo/statuses`;
- визуализация: легенда статусов и временная шкала на странице IFC Viewer.

## Ограничения

- балки относятся к `204.02.03.02` как `hypothesis` до утверждения бизнес-правила;
- у модели нет отдельного параметра КФО и нет секции;
- два элемента остаются в ветке `unknown`;
- JSON и IFC Viewer работают в read-only режиме и не изменяют `CurrentMap`, IFC или XML.
- временная шкала использует фактические даты там, где они есть; для будущих работ без факта сохраняется состояние `planned` и не прогнозируется фактическое выполнение.
