# Правила и результаты связей

Правила-источники находятся в `Статусы и маппинг IFC Временный/README.md` и
`Статусы и маппинг IFC Временный/STATUS_RULES.md`, редакция 19.10.2026.

Реализация находится в:

- `src/server/ifc-model.ts` — чтение свойств конкретной IFC-модели, исключение
  служебного элемента и назначение КФО с происхождением `rule_based/review`;
- `src/shared/location.ts` — корпус, секция и этаж из дерева XML;
- `src/server/monitoring.ts` — связь работ модели с работами графика и
  распространение агрегированного статуса работы на её элементы;
- `src/shared/status.ts` — статус на дату и отклонение от базового графика.

КФО не является самостоятельным доказательством связи. Из элементов IFC
сначала формируются работы модели по КФО, корпусу и этажу. Независимо от них из
операций формируются работы графика по тому же ключу. При совпадении связываются
две работы, а не элемент с одной конкретной операцией. Все операции внутри
работы графика сохраняются отдельно и продолжают иметь собственные статусы.

Для модели v2 КФО сначала читается из `Код по классификатору`, затем — из
системного параметра `Комментарий`/`Комментарии`. В актуальной IFC включён
5 491 элемент; у каждого прочитаны КФО, корпус и этаж. Работа v2 связывается с
работой графика при совпадении КФО и корпуса. Этаж сравнивается строго, если он
заполнен в графике; пустой этаж графика считается отсутствием детализации, а не
другим этажом. При наличии точного совпадения оно имеет приоритет над операцией
без этажа. Наличие нескольких операций внутри одной работы не считается
неоднозначностью. IFC-класс, имя элемента и ветка вида конструкции для v2 не
используются.
