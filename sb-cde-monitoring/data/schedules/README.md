# Локальное хранилище графиков

Приложение создаёт здесь `index.json` и отдельный каталог для каждого графика.
Каждая версия хранится неизменяемым снимком:

```text
<scheduleId>/versions/<versionId>/
  source.xml
  snapshot.json
```

`source.xml` — оригинал загрузки. `snapshot.json` — разобранные поля, иерархия,
календари и операции СМР. Новая загрузка не перезаписывает старую версию.
