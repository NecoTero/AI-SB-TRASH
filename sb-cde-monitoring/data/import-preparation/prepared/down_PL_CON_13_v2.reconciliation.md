## Главные риски

1. **Нельзя сопоставлять версии по ID/UID.** Совпадающих уникальных ID в диапазоне файлов много, но у **1039** новых операций такой ID относится к другой работе базового графика.
2. **Spider_Code пересоздан.** В обоих файлах поле заполнено у всех операций, но точных совпадений между версиями нет.
3. Структура действительно перестроена: в базе **1527** операций СМР, в новой версии **1743**.
4. Без КФО: база — **1243**, новая версия — **890**.
5. Без распознанного корпуса: **210**; без этажа: **722**.

## Безопасное сопоставление с базой

- Автоматически и однозначно сопоставлено: **370** из 1743 операций новой версии.
- Без надёжной пары в базе: **1373**.
- Базовых операций без пары в новой версии: **1157**.
- Сопоставление не использует даты и изменяемые ID: сначала проверяется полная смысловая комбинация, затем только глобально уникальные пары «название + КФО» и уникальные названия.
- Неоднозначные совпадения намеренно не создаются и перечислены в CSV.

- Подробный перечень проблем находится в CSV. Строка может повторяться, если у неё несколько независимых проблем.
